# Altai Production — AI-видеопродакшн для брендов

Премиальный одностраничный сайт-портфолио для **Altai Production**.

## Стек и особенности
- **Дизайн**: Кинематографичный темный фон (`#08080a`), благородное золото (`#E5B869`), фоновые эмбиент-градиенты и микро-сетка.
- **Типографика**: Google Fonts `Unbounded` (крупные акцентные заголовки) + `Inter` (текстовые блоки).
- **Сетка кейсов**: Адаптивная (2 колонки на десктопе, 1 на планшетах и мобильных).
- **16:9 Video Modal**: Модальное окно с iframe-плеером и поддержкой Kinescope и Rutube с автоплеем.
- **Единый массив данных**: Все кейсы вынесены в `js/cases.js` для простого добавления новых проектов.
- **Деплой**: Полная готовность к развертыванию на Vercel (включая `vercel.json` с настроенным кэшированием статики).

## Как добавить новый кейс
Откройте файл `js/cases.js` и добавьте объект в массив `casesData`:
```javascript
{
  id: "new-project",
  title: "Название бренда",
  category: "Формат ролика",
  year: "2026",
  embedUrl: "https://kinescope.io/embed/...",
  description: "Краткое описание проекта",
  accentGlow: "rgba(229, 184, 105, 0.25)",
  tagColor: "#E5B869",
  thumbnailTheme: "ostrovok" // или создайте новый визуал
}
```

## Развертывание на Vercel
1. Сделайте `git push` в репозиторий GitHub/GitLab.
2. Подключите репозиторий в [Vercel](https://vercel.com).
3. Vercel автоматически подхватит конфигурацию из `vercel.json` и опубликует сайт без дополнительных настроек.
